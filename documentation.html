Quick Start Guide

Welcome to CafePulse! Follow these steps to get the desktop application installed and configured with your local network environments.

1. Installation

Download the installer for your corresponding OS platform from the Download Page. Run the installation package and launch the CafePulse application from your desktop shortcut.

2. Verify Local Database

On startup, CafePulse automatically creates its database environment file: cafepulse.db in the installation path directory. All scans, settings parameters, and logs reside inside this local file database.

3. Router API Activation

For full operations controls (DHCP lease mappings, bulk voucher injection, system logs analytics), ensure the API services are enabled on your target MikroTik router. Follow the instructions detailed in the RouterOS API Setup section.

4. Run Your First Scan

Once configuration is set, input your Router credentials in the Connection Profiles tab and click Quick Scan to load details of active clients in real-time.
