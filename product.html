Adaptive Workspaces for Every Operator

CafePulse reflows its interface and controls dynamically depending on your active role, giving you the perfect tools for the task.

Business Workspace

Focused on venue metrics and performance reports. Ideal for coffee shop owners and venue managers.

  • Voucher sales and analytics
  • Peak traffic hour statistics
  • Network health logs & system alerts
  • Exportable PDF operations summary

Operations Workspace

Optimized for daily tasks, voucher generation, and client observations. Ideal for shop operators and clerks.

  • Bulk voucher creator (up to 500 codes)
  • Printable PDF templates
  • Active client tracking & search
  • Automatic database backups

Network Workspace

Full configuration layout for interfaces, DHCP allocations, and table details. Ideal for network technicians.

  • DHCP lease binding and static assignment
  • Local IP & Subnet discovery checks
  • DNS cache tables & lookup logs
  • VLAN configurations layout

Advanced Workspace

Advanced automation scripts, firewall controls, and command execution profiles. Ideal for network engineers.

  • Rule checkers and port forwarding logs
  • MikroTik native scheduler mappings
  • Watchdog services & system recovery config
  • Direct CLI script injection

Designed for Real-World Deployments

A professional operational system needs deep tooling. CafePulse includes modules built from field feedback.

Local OUI Device Lookup

Maintains a localized manufacturer MAC cache so that connected devices immediately resolve to standard vendor descriptions (Apple, Samsung, Espressif, etc.) without hitting external APIs.

Fail-safe Auto Reconnect

Utilizes a thread-safe connection check with capped exponential backoff. If a router power-cycles or disconnects, CafePulse auto-restores widgets once the port becomes reachable.

Secure Credentials Vault

Router passwords and API credentials are encrypted and stored locally. Your credentials never cross the local interface card and are never shared over the web.
