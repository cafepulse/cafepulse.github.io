# CafePulse Official Discord Server: Architecture Blueprint

This blueprint outlines the category structures, channel configurations, permissions, and roles for the official CafePulse community server.

---

## 1. Role Hierarchy & Permissions

To maintain a clean and professional community, the following role system is implemented:

- **Developer** (Owner): Full administrative rights.
- **Moderator**: Moderation rights (mute, kick, message cleaning).
- **Founder**: Restricted role for the 100 Founder Program members. Grants read/write access to the private Founder channels.
- **Beta Tester**: Role for the 10 active beta testers. Grants access to the private Beta Testing channel.
- **Community Advisor**: Highly active members recognized for helping others.
- **Professional User**: Verification role for users with activated Pro licenses.
- **Member**: Default role for new visitors.

---

## 2. Server Categories & Channels

### 2.1 Category: WELCOME (Public Read-Only)
- **`#rules`**: Server rules, code of conduct, and warnings.
- **`#announcements`**: Product updates, releases, and alerts (written by Developer/Moderator).
- **`#founder-info`**: Explanation of the Founder Program and application link.

### 2.2 Category: COMMUNITY (Public)
- **`#general-chat`**: General networking and introduction discussions.
- **`#showcase`**: Screen snaps of user network setups and dashboards.

### 2.3 Category: SUPPORT (Public / Pro)
- **`#help-desk`**: Peer support for installation and connection.
- **`#pro-tickets`**: Channel for Pro users to open support tickets.

### 2.4 Category: BETA TESTING (Private)
- **`#beta-chat`**: Discussions about experimental features. *Accessible only to Beta Tester and Developer.*
- **`#bug-reports`**: Thread lists of active bugs.

### 2.5 Category: FOUNDER PROGRAM (Private)
- **`#founder-lounge`**: Private chat. *Accessible only to Founder, Community Advisor, and Developer.*
- **`#roadmap-voting`**: Polls to decide which features get implemented next.

### 2.6 Category: MIKROTIK DISCUSSION (Public)
- **`#routeros-tips`**: RouterOS scripts and setup guides.
- **`#rt-rw-net`**: Discussions for RT/RW net operators.

### 2.7 Category: CAFEPULSE DISCUSSION (Public)
- **`#feature-requests`**: Suggestions for updates.
- **`#faq`**: Frequently Asked Questions.

### 2.8 Category: DEVELOPMENT (Public)
- **`#dev-logs`**: Raw technical logs from the developer.

### 2.9 Category: OFF TOPIC (Public)
- **`#random`**: Memes and unrelated topics.
