# About Developer Section Design Specification

This document outlines the visual layout and design specification for the Developer Profile, Project Story, and Contact information cards.

---

## 1. Design Overview
The developer profile is designed to showcase Solo Developer ownership with a high-fidelity commercial presentation. It rejects basic "biodata" styles in favor of clean structural grid layouts that convey professionalism and authenticity.

---

## 2. Layout Structure

```
+--------------------------------------------------------------+
| Developer Profile (Card)     | Official Contact (Card)       |
| Name: Founder & Solo Dev     | Web: https://cafepulse.com    |
| Country: Indonesia           | Email: support@cafepulse.com  |
+------------------------------+-------------------------------+
| The Story Behind CafePulse (Card)                            |
| "Fokus pada operasional jaringan nyata, MikroTik, Hotspot..." |
+--------------------------------------------------------------+
```

### 2.1 Developer Profile Card Details
- **Developer Name:** Rendered in bold, high-contrast text.
- **Designation:** Founder & Solo Developer
- **Location Badge:** Rendered with a clean regional indicator: `Indonesia` with a subtle green/blue highlight.
- **Narrative:** Explains the commitment to independent software engineering and offline utility focus.

### 2.2 Project Story Card Details
- Details the real-world operational challenges in managing cafes, restaurants, and shared workspaces.
- Emphasizes the need for dedicated MikroTik monitoring tools that do not require cloud subscriptions.

### 2.3 Contact Card Details
- Uses clickable action buttons for **Website**, **Support Email**, and **Discord Community** featuring hover micro-animations.
