# Copyright & License Section Specification

This document details the visual and licensing presentation cards of the CafePulse About Page.

---

## 1. Design Overview
The licensing and copyright sections are critical for building confidence in the software's commercial integrity. This section displays terms for both the Free/Basic and Professional editions in side-by-side or stacked card grids.

---

## 2. Layout Structure

```
+--------------------------------------------------------------+
| License Agreement & Copyright (Card)                         |
| "Copyright (c) 2026 CafePulse. All rights reserved."         |
+------------------------------+-------------------------------+
| Free Edition Terms (Card)    | Professional Edition (Card)   |
| - Free for personal use      | - One-time purchase (1 PC)    |
| - Commercial use permitted   | - 5-Year Update Entitlement   |
+------------------------------+-------------------------------+
| Source Code & Trademark Notice (Card)                        |
| - Redistribution prohibited without written consent          |
| - CafePulse logo/branding is protected intellectual property  |
+--------------------------------------------------------------+
```

### 2.1 Copyright Display
- **Legal Notice:** `Copyright (c) CafePulse. All rights reserved.`
- **Platform Name:** `CafePulse — Network Operations Platform`
- **Copyright Year:** `Copyright (c) 2026 CafePulse`

### 2.2 Free vs. Pro Edition Cards
- **Free Card:** Uses muted borders to show its general availability status.
- **Pro Card:** Outlines the 1-PC workstation locking, online/offline activation channels, and the 5-year update support terms (with a clarifying note that the software remains fully functional after the support term expires).

### 2.3 Trademark and Code Protection Disclaimers
- Outlines intellectual property guidelines and redistribution restrictions.
