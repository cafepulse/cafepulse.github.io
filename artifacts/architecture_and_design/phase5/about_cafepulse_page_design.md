# About CafePulse Section Design Specification

This document details the visual and UI specifications for the Product Overview, Vision, and Long-Term Direction sections of the CafePulse About Page.

---

## 1. Design Overview
The "About CafePulse" section occupies the top portion of the page content layout. It is structured as a premium horizontal or vertical split card layout to present the core product data in an engaging, scannable format.

---

## 2. UI Components & Layout

```
+--------------------------------------------------------------+
|                   CafePulse Logo & Title                     |
+------------------------------+-------------------------------+
| About CafePulse (Card)       | Product Vision (Card)         |
| "CafePulse adalah platform..."| "Menyederhanakan operasi..."  |
+------------------------------+-------------------------------+
| Long-Term Direction (Card)                                  |
| - Monitoring, Analytics, Network Ops, MikroTik, Insight...  |
+--------------------------------------------------------------+
```

### 2.1 Typography & Stylesheet
- **Section Headers:** Size `16px`, bold, cyan color (`#38BDF8`).
- **Body Text:** Size `13px`, line-height `1.5`, color `#94A3B8` (Dark) / `#475569` (Light).
- **Cards (`#DashCard`):**
  - **Dark Theme:** Background `#1E293B`, border `1px solid #374151`, border-radius `8px`.
  - **Light Theme:** Background `#FFFFFF`, border `1px solid #E2E8F0`, border-radius `8px`.

---

## 3. Product Vision & Long-Term Direction Content
- **Vision Panel:** Styled with a subtle left border gradient (Cyan-to-Purple) to emphasize its core importance.
- **Direction Panel:** Includes sub-headings for *Monitoring*, *Analytics*, *Network Operations*, *MikroTik Management*, *Business Insights*, and *Customer Engagement*.
