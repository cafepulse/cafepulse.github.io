## 2. Palette & Contrast System

To maintain the premium look of the desktop app, the website is styled with a sleek, high-contrast dark palette, highlighted by cyan/sky-blue indicators:

- **Surface Primary (`#0F1117`)**: Main page backgrounds.
- **Surface Secondary (`#161B27`)**: Container cards, navigation banners, footer backgrounds.
- **Surface Tertiary (`#1E2535`)**: Borders, table headers, inactive buttons.
- **Brand Accent (`#38BDF8`)**: Anchors, focus elements, price tags, important status pills.
- **Brand Accent Dark (`#0EA5E9`)**: Active buttons, primary CTA states.
- **Text Light (`#F1F5F9`)**: Headings, body titles, active links.
- **Text Muted (`#94A3B8`)**: Body text, table rows, descriptive labels.
- **Glow Shadow (`rgba(56, 189, 248, 0.1)`)**: Active state highlighting and cards styling.

---

## 3. Typography & Hierarchy

The styling pulls modern type scales from Google Fonts rather than utilizing standard browser defaults:

- **Primary Font**: `Inter`, `Segoe UI`, Arial, sans-serif.
- **Titles / Headings**: Bold weight (`700` and `800`) with letter-spacing.
- **Body Text**: Regular weight (`400`) with comfortable line-height (`1.6`).
- **Monospace Details**: `Consolas`, `Fira Code`, monospace (for code snippets).
