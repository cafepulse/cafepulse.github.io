# CafePulse Feedback Template

Gunakan format ini saat memberikan saran, ide fitur, keluhan pengalaman pengguna (UX), atau masalah performa lambat di server Discord/Telegram kami.

```markdown
**[FEEDBACK]**
**Kategori:** (Pilih salah satu: UX & Tampilan / Performa / Ide Fitur Baru / Dokumentasi)

**Bagian Aplikasi yang Dibahas:**
(Contoh: Halaman Dasbor Utama / Generate Voucher PDF / Website Unduhan)

**Apa yang Anda Rasakan/Temukan? (Deskripsi Singkat):**
(Contoh: Proses generate 500 voucher memakan waktu hampir 2 menit, membuat aplikasi seolah-olah hang / *freeze*).

**Mengapa Ini Mengganggu / Penting bagi Anda?:**
(Contoh: Sebagai teknisi, saya sering ditunggu klien saat men-generate ratusan voucher. Jika aplikasi terlihat *hang*, saya jadi ragu apakah harus menutupnya paksa atau tidak).

**Saran Solusi atau Ekspektasi Anda:**
(Contoh: Tolong tambahkan *Loading Progress Bar* beranimasi dengan estimasi waktu yang tersisa, agar kami tahu aplikasinya masih memproses).

**Seberapa Kritis Saran Ini?:**
(Pilih: Rendah - *Nice to have* / Sedang - *Cukup penting* / Tinggi - *Sangat menghambat pekerjaan saya*)
```
