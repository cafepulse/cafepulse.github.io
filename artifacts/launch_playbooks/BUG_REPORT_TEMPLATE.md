# CafePulse Bug Report Template

Gunakan format ini saat melaporkan error atau crash di server Discord/Telegram kami. Salin (copy) teks di bawah ini dan isi informasinya secara mendetail.

```markdown
**[BUG REPORT]**
**Judul Ringkas:** (Contoh: Aplikasi crash saat generate 500 voucher PDF)

**Informasi Sistem:**
- Versi CafePulse: (Contoh: 1.1.0-alpha.1 Free)
- Sistem Operasi: (Contoh: Windows 11 22H2 / Ubuntu 22.04)
- Jenis Instalasi: (Contoh: Installer EXE / Portable ZIP / AppImage)
- Model Router MikroTik: (Contoh: RB750Gr3)

**Langkah Reproduksi (Cara memunculkan bug ini):**
1. Buka aplikasi dan masuk ke tab...
2. Klik tombol...
3. Isi kolom A dengan nilai...
4. Lalu terjadi...

**Hasil Aktual (Apa yang terjadi?):**
(Contoh: Aplikasi tertutup sendiri tanpa pesan error, atau muncul popup tulisan "Database Locked".)

**Hasil yang Diharapkan (Apa yang seharusnya terjadi?):**
(Contoh: Seharusnya muncul loading bar dan file PDF tersimpan di folder Exports.)

**Lampiran Wajib (Log File):**
- [ ] Saya telah melampirkan file `cafepulse.log` atau file dari folder `crash/`.
*(Cara menemukan log: Di Windows tekan Win+R, ketik `%LOCALAPPDATA%\CafePulse\logs` lalu Enter. Tarik/drag file ke chat ini).*

**Tangkapan Layar (Opsional namun disarankan):**
*(Sisipkan screenshot atau rekaman video pendek di sini jika error berupa visual/tampilan).*
```
