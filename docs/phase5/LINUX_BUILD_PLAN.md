### *Targeting Linux Distribution Foundation (Sprint 1) — Locked: Juni 2026*

## 1. LINGKUNGAN BUILD (BUILD ENVIRONMENT)

Proses kompilasi biner Linux untuk CafePulse direkomendasikan berjalan pada lingkungan clean runner Linux yang konsisten.
- **Rekomendasi Host/OS:** **Ubuntu 22.04 LTS** (atau image `ubuntu-latest` pada GitHub Actions runner).
- **Python Version:** **Python 3.12** (agar selaras dengan lingkungan Windows).
- **System Dependencies (Prerequisites):** PyQt6 membutuhkan runtime Qt6 yang memerlukan dynamic library X11/GL pada system host. Library berikut wajib diinstal pada build environment sebelum menjalankan PyInstaller:
  ```bash
  sudo apt-get update
  sudo apt-get install -y \
      libegl1 \
      libgl1-mesa-glx \
      libxcb-xinerama0 \
      libxkbcommon-x11-0 \
      libxcb-icccm4 \
      libxcb-image0 \
      libxcb-keysyms1 \
      libxcb-randr0 \
      libxcb-render-util0 \
      libxcb-shape0 \
      libxcb-shm0 \
      libxcb-sync1 \
      libxcb-util1 \
      libxcb-xfixes0 \
      libxcb-xkb1 \
      libxkbcommon0
  ```

## 2. FORMAT KEMASAN (PACKAGING SYSTEM)

- **Format Utama:** **AppImage**
  - **Mengapa AppImage?** Format ini mewakili prinsip *local-first* dan *portable* secara native di ekosistem Linux. AppImage membundel aplikasi beserta semua library dependensinya ke dalam satu berkas `.AppImage` mandiri. Pengguna tidak perlu melakukan instalasi (tidak memerlukan hak akses `root` atau `sudo`), melainkan cukup membuat berkas menjadi executable (`chmod +x`) dan langsung menjalankannya.
  - **Distribusi:** AppImage akan dipublikasikan ke GitHub Releases sejajar dengan setup `.exe` Windows.
- **Format yang Dikesampingkan (Founder Phase):**
  - **Snap & Flatpak:** Dihindari karena membutuhkan integrasi sandbox yang rumit dan konfigurasi izin akses network socket/raw CLI tool (`ping`/`arp`) yang membatasi operasional CafePulse.
  - **RPM & DEB:** Dihindari karena memerlukan maintenance repositori paket terpisah per distro.

## 3. STRATEGI PYINSTALLER LINUX

Kompilasi PyInstaller di Linux akan memanfaatkan struktur konfigurasi yang ada di dalam `CafePulse.spec` dengan beberapa penyesuaian otomatis:
- **Nativitas Kompilasi:** PyInstaller harus dieksekusi secara native di atas mesin Linux (tidak bisa cross-compile dari Windows).
- **Spec File Compatibility:** Berkas `CafePulse.spec` menggunakan path relatif berbasis `SPEC_DIR` (PyInstaller `SPECPATH`), sehingga secara default **sudah kompatibel untuk build Linux** tanpa perlu memodifikasi isi spec file.
- **Qt6 Plugins & Libraries:** PyInstaller secara otomatis memetakan dan membundel plugin PyQt6 (`PyQt6/Qt6/plugins/platforms/libqxcb.so`) ke dalam subdirektori biner. Dynamic libraries Qt ini akan dimuat otomatis saat AppImage diekstrak di runtime memori.

---

## 4. INTEGRASI DATABASE (SQLITE)

- **Kesesuaian:** SQLite3 didukung secara native oleh kernel Linux.
- **Write-Ahead Logging (WAL) Mode:** Sistem berkas Linux (seperti EXT4, XFS, Btrfs) mendukung penuh operasi locking WAL dan shared memory (`.shm` & `.wal` files) secara berbarengan (concurrent read/write) tanpa mengalami kebuntuan (database lock).
- **Penyimpanan:** Database `cafepulse.db` akan diletakkan di direktori writable pengguna (user's home directory).

---

## 5. SKEMA LISENSI & HARDWARE LOCKING

Sistem lisensi CafePulse menggunakan validasi tanda tangan kriptografi RSA-4096. Parameter lisensi diikat ke Hardware ID (HWID) komputer.
- **Windows:** HWID diikat ke Registry `MachineGuid`.
- **Linux Adaptasi:** Pada sistem Linux, HWID akan diturunkan secara deterministik dengan algoritma SHA-256 dari kombinasi parameter berikut:
  1. `/etc/machine-id` (Unique boot/install ID generated by systemd).
  2. Motherboard UUID (bila terjangkau).
  3. MAC Address Primer (`uuid.getnode()`).
- **Keamanan:** Kunci publik RSA tersemat di dalam biner terkompilasi, menjamin integritas verifikasi lisensi offline di Linux berjalan sekokoh versi Windows.
