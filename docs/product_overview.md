# Product Overview

**CafePulse** adalah *Network Operations Platform* berbasis desktop (Local-First) yang dirancang khusus untuk administrator jaringan MikroTik, khususnya yang mengelola ekosistem Hotspot.

Tidak seperti sistem *cloud radius* konvensional, CafePulse berjalan sepenuhnya secara lokal (Offline) di PC Windows atau Linux Anda. CafePulse bukan sekadar *"Winbox Companion"* atau alat konfigurasi *router*, melainkan pusat operasi (*Operations Center*) untuk memantau trafik, membuat cetak *voucher*, menganalisis log, dan memantau kesehatan jaringan secara seketika (*real-time*).

### Fitur Utama

1. **Local-First Architecture:** Semua data disimpan di dalam database SQLite lokal pada PC Anda (dienkripsi). Tidak ada langganan *cloud*, tidak ada sinkronisasi server eksternal. Anda mengontrol penuh privasi jaringan Anda.
2. **Dashboard Real-Time:** Memantau pengguna Hotspot aktif, penggunaan *bandwidth*, dan status *uptime* router menggunakan koneksi API (Port 8728/8729).
3. **Voucher Generation & Management:** Membuat profil paket internet (berbasis waktu/kuota) dan memproduksi *voucher* massal (PDF) tanpa perlu alat tambahan.
4. **Offline Licensing:** Pembelian lisensi Professional dilakukan sekali (One-Time Purchase) dengan aktivasi menggunakan kriptografi RSA-4096 sepenuhnya tanpa internet.

### Posisi CafePulse
CafePulse tidak menggantikan peran Winbox untuk konfigurasi *routing*, *firewall*, atau instalasi awal jaringan. CafePulse melengkapi infrastruktur Anda di sisi **Operasional Harian** (*Daily Operations*) seperti manajemen pelanggan, pembatasan kecepatan, dan analitik laporan harian.
