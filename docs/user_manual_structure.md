# User Manual Structure

Dokumentasi CafePulse dirancang secara terstruktur untuk membantu Anda memahami konsep, instalasi, dan penyelesaian masalah. Anda dapat menavigasi bagian-bagian dokumentasi menggunakan bilah menu di sebelah kiri layar.

### 1. Get Started (Persiapan)
Berisi panduan dasar bagi Anda yang baru pertama kali menggunakan CafePulse:
- **Quick Start Guide:** Ringkasan alur dari instalasi hingga pemantauan pertama.
- **Product Overview:** Gambaran besar fungsi dan arsitektur produk.
- **Installation & First Launch:** Petunjuk pemasangan dan penyiapan database.
- **RouterOS API Setup:** Cara menghubungkan *software* ke perangkat keras MikroTik.

### 2. Beta & Troubleshooting (Pemecahan Masalah)
Ditujukan khususnya bagi peserta program Beta atau jika Anda menemui kendala di lapangan:
- **Validation Program:** Prosedur pelaporan kompatibilitas perangkat keras.
- **Troubleshooting:** Daftar masalah umum (Timeout, API Error) beserta solusi instannya.
- **Bug Reporting Guide:** Tata cara mengumpulkan *log* dan melaporkannya ke tim pengembang.

### 3. Operations & Security (Operasional Tingkat Lanjut)
Didedikasikan untuk Administrator Jaringan yang peduli pada keamanan dan integritas data:
- **Security Model:** Penjelasan algoritma keamanan (AES-256) pada penyimpanan kredensial.
- **Backup & Recovery:** Cara mencadangkan *database* operasional Anda.

### 4. Legal Policy (Kebijakan Hukum)
Menguraikan syarat, ketentuan, perjanjian lisensi pengguna akhir (EULA), kebijakan pengembalian dana, dan privasi yang mengikat secara hukum.
