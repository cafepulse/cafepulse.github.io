# Privacy Policy (Kebijakan Privasi)

Kami di CafePulse sangat menghargai dan melindungi privasi data Anda. Kebijakan ini menjelaskan dengan transparan bagaimana perangkat lunak kami beroperasi.

### 1. Data Jaringan Lokal Anda
CafePulse dirancang dengan prinsip **Local-First Architecture**. Ini berarti:
* Semua data konfigurasi *router*, kredensial *login* API, dan riwayat alamat MAC pengguna Hotspot Anda disimpan **secara lokal** di *hard drive* Anda.
* Kami **TIDAK** pernah mengirim *log* jaringan, nama pengguna, atau kata sandi MikroTik Anda ke server eksternal kami.
* Tidak ada skrip pelacakan (*telemetry*) atau analitik awan yang diintegrasikan ke dalam rilis *software* kami.

### 2. Data Pemrosesan Lisensi (Offline)
Saat Anda memproses lisensi Professional Edition:
* Kami hanya menyimpan Alamat Email Anda dan ID Perangkat Keras PC Anda (HWID) untuk keperluan pencocokan identitas kriptografis.
* Karena aktivasi menggunakan metode *Offline RSA*, PC Anda tidak perlu melakukan "ping balik" ke server kami untuk memeriksa lisensi secara berkala. Lisensi sepenuhnya divalidasi oleh PC Anda.

### 3. Pihak Ketiga
Situs dokumentasi kami (dihosting di GitHub Pages) mungkin menggunakan analitik halaman dasar (seperti jumlah kunjungan). Namun, aplikasi CafePulse desktop itu sendiri tidak mengandung SDK pihak ketiga.
