## 2. Unlocking Professional Modules
The Free Edition contains embedded locked widgets (e.g. Analytics, MikroTik Observability). These can be unlocked in real-time by entering a valid Professional license key inside the **Licensing & Settings** panel. No re-installation or data loss is incurred during this migration.
