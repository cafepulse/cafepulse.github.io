# Editions Comparison

CafePulse tersedia dalam dua edisi: **Free Edition** (Gratis) dan **Professional Edition** (Berbayar). Kedua edisi berjalan secara lokal tanpa memerlukan langganan *cloud*.

| Fitur | Free Edition | Professional Edition |
| :--- | :--- | :--- |
| **Harga** | Gratis (Selamanya) | Rp 499.000 (Sekali Beli) |
| **Koneksi Router** | Maks. 1 Router Profile | **Tidak Terbatas** (Unlimited) |
| **Dashboard & Monitoring** | Ya | Ya |
| **Manajemen Pengguna Aktif** | Ya | Ya |
| **Generate Voucher** | Maks. 10 / Batch | **Ribuan / Batch** |
| **Kustomisasi Cetak Voucher** | Desain Dasar | **Template Kustom (HTML/CSS)** |
| **Ekspor Data** | Terbatas (CSV) | **Penuh (CSV, PDF, Excel)** |
| **Multi-Threading Polling** | Standard Polling | **High-Performance (WAL Mode)** |
| **Prioritas Dukungan** | Komunitas / Forum | **Prioritas (Email/Tiket)** |
| **Pembaruan Fitur** | Minor Updates | **Semua Pembaruan Mayor & Minor** |

### Free Edition
Ditujukan bagi pengguna rumahan, RT/RW Net kecil, atau teknisi yang ingin mengevaluasi *software* sebelum melakukan pembelian. Fungsionalitas inti tetap terbuka, hanya dibatasi pada batasan skala (kuantitas *voucher*, jumlah *router*).

### Professional Edition
Ditujukan bagi warung kopi, kafe, sekolah, atau pengelola jaringan menengah-besar yang membutuhkan kecepatan, kustomisasi cetak *voucher* bermerek sendiri, dan penanganan skala ratusan *active users* tanpa hambatan. Aktivasi dilakukan sekali seumur hidup (*Lifetime*) dengan sistem lisensi *Offline*.
