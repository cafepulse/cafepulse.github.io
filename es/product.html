Espacios de Trabajo Adaptativos para Cada Operador

CafePulse adapta su interfaz y controles dinámicamente según su rol activo, ofreciéndole las herramientas perfectas para la tarea.

Business Workspace

Enfocado en métricas del establecimiento e informes de rendimiento. Ideal para propietarios de cafeterías y gerentes.

  • Ventas de vouchers y analíticas
  • Estadísticas de horas pico de tráfico
  • Registros de estado de red y alertas del sistema
  • Exportación de resúmenes de operación en PDF

Operations Workspace

Optimizado para tareas diarias, generación de vouchers y observaciones de clientes. Ideal para operadores y dependientes.

  • Creador de vouchers masivos (hasta 500 códigos)
  • Plantillas PDF listas para imprimir
  • Seguimiento y búsqueda de clientes activos
  • Copias de seguridad automáticas de la base de datos

Network Workspace

Diseño de configuración completo para interfaces, asignaciones DHCP y tablas de detalles. Ideal para técnicos de red.

  • Vinculación de DHCP leases y asignación estática
  • Pruebas de descubrimiento de IP local y subred
  • Tablas de caché DNS y registros de búsqueda
  • Diseño de configuraciones de VLAN

Advanced Workspace

Scripts de automatización avanzados, controles de firewall y perfiles de ejecución de comandos. Ideal para ingenieros de red.

  • Verificadores de reglas y registros de reenvío de puertos
  • Mapeos de programador nativo de MikroTik
  • Servicios watchdog y configuración de recuperación del sistema
  • Inyección directa de scripts CLI

Diseñado para Despliegues del Mundo Real

Un sistema operativo profesional requiere herramientas profundas. CafePulse incluye módulos construidos a partir de comentarios en el campo.

Búsqueda de Dispositivos OUI Local

Mantiene una caché local de direcciones MAC de fabricantes para que los dispositivos conectados se resuelvan de inmediato a descripciones de proveedores estándar (Apple, Samsung, Espressif, etc.) sin consultar APIs externas.

Reconexión Automática Fail-safe

Utiliza una verificación de conexión segura para subprocesos con retroceso exponencial limitado. Si el router se apaga o se desconecta, CafePulse restaura los widgets cuando el puerto vuelve a estar accesible.

Bóveda de Credenciales Segura

Las contraseñas del router y credenciales de API se cifran y almacenan localmente. Sus credenciales nunca cruzan la tarjeta de interfaz de red local y nunca se comparten en la web.
